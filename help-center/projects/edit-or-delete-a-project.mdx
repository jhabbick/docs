## What you'll accomplish

Edit project information or delete a project you no longer need.

## Edit project details

1. Open the project and go to the **Overview** tab.
2. In **Project Details**, click **Edit**.
3. Change any fields — title, description, location, dates, budget, or goals.
4. Click **Save** or **Cancel**.

<Tip>
  If you navigate away from the **Overview** tab with unsaved edits, Envoy asks you to confirm before discarding changes.
</Tip>

## Delete a project

Deleting a project is permanent.

1. Open the project **Overview** tab.
2. Click **Delete project**.
3. In the confirmation dialog (**Delete project?**), confirm by clicking **Delete project** again.

Once deleted, the project is removed from your dashboard and sidebar project list.

<Warning>
  Deleting a project cannot be undone. Outreach threads and project-specific data associated with that project will no longer be accessible from Envoy.
</Warning>

## What you'll learn

The **Dashboard** is your home base after signing in. It shows recent projects and gives you quick access to create new ones.

## Getting there

Click **Dashboard** in the sidebar, or go to [Dashboard](https://app.hello-envoy.com/dashboard).

## What you'll see

### When you have projects

- A greeting: **Jump back in, [name]**
- **Recent projects** — Up to three of your most recent projects with quick links
- A **+ New project** button to start the creation wizard

### When you have no projects

If you haven't created a project yet, you'll see:

- **No projects yet**
- **Create your first project** — Opens the project wizard

## Sidebar navigation

The sidebar is always available on authenticated pages:

| Link | Purpose |
|------|---------|
| **Dashboard** | Home and recent projects |
| **Contacts** | Global contacts directory |
| **New Project** | Opens the creation wizard |
| **Projects** | List of your active projects |
| **Help Center** | Opens these docs in a new tab |
| **Account** | Settings, connected email, and default location |
| **Logout** | Sign out |

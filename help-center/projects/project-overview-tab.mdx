## What you'll accomplish

Manage project details and contacts from the **Overview** tab inside a project.

## Open the Overview tab

1. Open a project from **Dashboard** or the sidebar **Projects** list.
2. The **Overview** tab is selected by default. If not, click **Overview** in the tab bar.

![Project Overview](/images/projects/project-overview.png)

## View project details

The **Project Details** section shows:

- Title and description
- Location (ZIP code or full address)
- Budget
- Deadline

If a field hasn't been added yet, you'll see **Not set**.

## Edit project details

1. Click **Edit** in the Project Details section.
2. Update any fields. For **Location**, enter a ZIP code or full address and select a suggestion.
3. Click **Save** to keep changes or **Cancel** to discard.

You can also ask Envoy on the **Chat** tab to update these same fields — see [Chat planning](/help-center/projects/chat-planning#update-project-details-from-chat).

## Manage contacts

The **Contacts** section shows everyone attached to this project.

### Attach existing contacts

1. Click **+ Attach existing**.
2. Search your contacts directory and select who to add.

### Add a new contact manually

1. Click **+ New contact**.
2. Enter name and email.
3. If Envoy finds a trusted listing match, choose **Use listing** or **Create separate contact**.

### Find new contacts

1. Click **🔍 Find new contacts**.
2. Search by project description and location.
3. Select contacts to add to the project.

If no contacts are attached, you'll see: *No contacts yet. Attach contacts here so Envoy can draft outreach emails for them.*

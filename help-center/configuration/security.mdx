Envoy provides a layered set of security controls to help you protect your organization's data and manage how members authenticate. Whether you need to enforce two-factor authentication across your team, connect an identity provider via SSO, or restrict access to trusted IP ranges, all security settings are available under **Settings → Security**.

## Two-Factor Authentication

Two-factor authentication (2FA) adds a second layer of identity verification at login. Envoy supports authenticator apps (TOTP) and SMS as second factors.

**Enforce 2FA organization-wide:**
Navigate to **Settings → Security → Two-Factor Authentication** and toggle **Require 2FA for all members**. Once enabled, any member who has not yet set up 2FA will be prompted to complete enrollment on their next login before accessing the workspace.

**Per-user 2FA:**
Individual members can enable 2FA from their **Profile → Security** page without requiring an org-wide mandate. Admins can see each member's 2FA enrollment status in **Settings → Members**.

<Note>
  If a member loses access to their 2FA device, an organization admin can reset their 2FA enrollment from the Members management panel.
</Note>

## Single Sign-On (SSO)

SSO allows your team to authenticate with Envoy using your existing identity provider (IdP). Envoy supports both **SAML 2.0** and **OIDC** protocols. SSO is available on the **Enterprise plan**.

<Tabs>
  <Tab title="SAML 2.0 Setup">
    Follow these steps to configure SAML 2.0 SSO between your identity provider and Envoy.

    <Steps>
      <Step title="Obtain your IdP Metadata URL">
        Log in to your identity provider (e.g., Okta, Azure AD, Google Workspace) and locate the SAML metadata URL or download the metadata XML file for your Envoy application.
      </Step>
      <Step title="Configure the Envoy application in your IdP">
        In your IdP, create a new SAML application for Envoy. Set the following values:
        - **Single Sign-On URL (ACS URL):** Retrieved from Envoy in the next step.
        - **Audience URI (Entity ID):** `https://app.envoy.com/saml/metadata`
        - **Name ID Format:** `EmailAddress`
        - **Attribute mapping:** Map `email`, `firstName`, and `lastName` from your IdP's user profile.
      </Step>
      <Step title="Enter your ACS URL in Envoy">
        In Envoy, go to **Settings → Security → Single Sign-On** and select **SAML 2.0**. Paste your IdP's metadata URL (or upload the XML file) and copy the **ACS URL** displayed. Return to your IdP and update the application with this ACS URL.
      </Step>
      <Step title="Test your SSO login">
        Click **Test SSO Connection** in the Envoy SAML configuration panel. Envoy will open a test login flow in a new tab. Confirm that authentication completes successfully before enabling SSO for all members.
      </Step>
    </Steps>
  </Tab>
  <Tab title="OIDC Setup">
    Follow these steps to configure OpenID Connect (OIDC) SSO for your organization.

    <Steps>
      <Step title="Register Envoy as an OIDC client">
        In your identity provider, create a new OIDC application. Set the **Redirect URI** to the value shown in **Settings → Security → Single Sign-On → OIDC** in Envoy.
      </Step>
      <Step title="Copy your client credentials">
        After registering the application, your IdP will provide a **Client ID** and **Client Secret**. Keep these values secure.
      </Step>
      <Step title="Enter credentials in Envoy">
        In Envoy, go to **Settings → Security → Single Sign-On** and select **OIDC**. Enter your **Issuer URL**, **Client ID**, and **Client Secret**, then save.
      </Step>
      <Step title="Test and enable">
        Click **Test OIDC Connection** to verify the configuration. Once confirmed, toggle **Enable SSO** to enforce OIDC authentication for your organization.
      </Step>
    </Steps>
  </Tab>
</Tabs>

<Tip>
  You can configure SSO in **audit-only mode** first, which logs SSO events without enforcing it for all members. This lets you validate the configuration before a full rollout.
</Tip>

## IP Allowlisting

IP allowlisting restricts Envoy access to requests originating from specific IP ranges, providing an additional network-level security boundary. This feature is available on the **Enterprise plan**.

To configure IP allowlisting, navigate to **Settings → Security → IP Allowlist** and add one or more CIDR ranges (e.g., `203.0.113.0/24`).

<Warning>
  Before saving your IP allowlist, ensure that your current IP address falls within one of the CIDR ranges you have entered. Saving a list that excludes your own IP will immediately lock you out of your account. If this happens, contact Envoy Enterprise Support to have the allowlist temporarily suspended.
</Warning>

- You can add multiple CIDR ranges to accommodate office networks, VPNs, and CI/CD infrastructure.
- IPv4 and IPv6 ranges are both supported.
- Changes take effect immediately for all members.

## Audit Logs

Audit logs provide a tamper-evident record of security-relevant events in your organization. Audit logs are available on **Growth and Enterprise plans**.

**What is logged:**
- Member invitations, role changes, and removals
- SSO and 2FA configuration changes
- API key creation and revocation
- Workspace creation, updates, and deletion
- Login events including failures and SSO authentications
- Billing and subscription changes

**Exporting audit logs:**
Navigate to **Settings → Security → Audit Logs**. You can filter by date range, event type, and actor, then export results as a CSV file. Enterprise customers can also stream audit logs to an external SIEM via the Envoy API.

## Session Management

Envoy allows organization administrators to control session lifetimes and review active sessions.

- **Session Timeout** — Set an inactivity timeout (15 minutes to 30 days) under **Settings → Security → Sessions**. Members will be logged out automatically after the configured idle period.
- **Active Sessions** — View and revoke individual active sessions for any member from the **Members** panel. This is useful for offboarding or incident response scenarios.

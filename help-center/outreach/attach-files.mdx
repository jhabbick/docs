## What you'll accomplish

Attach files to an outreach draft or reply, and download files contacts send back.

## Before you start

- An open draft or reply composer on the **Outreach** tab
- A connected Gmail or Microsoft inbox — see [Connect your email](/help-center/outreach/connect-your-email)

## Attach files to a draft or reply

1. Open your project and select the **Outreach** tab.

2. Open a draft (**New message** → **Create draft**) or click **Reply** on a thread.

3. In **Attachments**, drop files onto the dashed area or click **Attach files**.

   ![Attach files in outreach](/images/outreach/attach-files.png)

4. Wait until each file shows **Ready**. Remove a file if you added it by mistake.

5. Click **Approve & Send** or **Send reply**. If uploads are still in progress, you'll see **Waiting for uploads...**. While sending, you may see **Sending N attachment(s)...**.

## Size and count limits

The **Attachments** area shows the limits for your connected inbox. Typical limits:

- Up to **10 files** per message
- Up to **10 MB** per file

Outlook and Microsoft inboxes may allow a **smaller total size** for the whole message. Follow the hint under **Attachments** if a file is rejected.

## Download files from a thread

When a contact sends files back — or you send files out — they appear on the message in the thread. Click a file to download it.

If a file can't be downloaded, Envoy shows **Unavailable for download** or **Blocked for security**.

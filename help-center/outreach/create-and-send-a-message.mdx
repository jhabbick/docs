## What you'll accomplish

Create an Envoy-drafted outreach email, review it, and send it to a contact from your connected inbox.

## Before you start

- A project with at least one contact attached on the **Overview** tab
- A connected Gmail or Microsoft inbox — see [Connect your email](/help-center/outreach/connect-your-email)
- Contacts must have valid email addresses

## Steps

1. Open your project and select the **Outreach** tab.

2. Click **New message**.

3. Select the contact you want to reach from the dropdown.

4. Click **Create draft**. Envoy generates a subject line and message body based on your project details.

   ![Outreach compose](/images/outreach/new-message.png)

5. Review the draft. Edit the **Subject** or **Body** directly if you want to make manual changes.

6. When you're satisfied, click **Approve & Send**.

7. Wait for confirmation. The message status changes to **Sent** when delivery succeeds.

## If you see empty states

| Message | What to do |
|---------|------------|
| **No contacts are linked to this project yet** | Add contacts on the **Overview** tab first |
| **Your linked contacts do not have email addresses** | Edit contacts to add email addresses |
| **Connect an inbox to send outreach** | Connect Gmail or Microsoft from **Account** |
| **No threads yet** | Click **New message** to create your first draft |

## Cancel or retry

- **Cancel draft** — Discard a draft you don't want to send
- **Retry draft generation** — Ask Envoy to regenerate if the first draft didn't come out right

## What you'll accomplish

Change how Envoy looks by selecting a color theme.

## Steps

1. Go to **Account**.
2. Find the **Appearance** section with **Color theme**.
3. Choose one of:

   | Option | Behavior |
   |--------|----------|
   | **Light** | Always use light mode |
   | **System** | Match your device preference |
   | **Dark** | Always use dark mode |

4. The theme applies immediately across the app.

<Tip>
  **System** is a good default — Envoy follows your OS light/dark setting automatically.
</Tip>

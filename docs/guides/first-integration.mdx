Envoy's integration directory lets you connect the tools your team already uses — from communication platforms to project trackers — so everything works together without manual handoffs. This guide walks you through connecting Slack as your first integration and points you toward what to explore next.

## Connect Slack to Envoy

<Steps>
  <Step title="Navigate to Settings → Integrations">
    From your Envoy dashboard, click **Settings** in the left sidebar, then select **Integrations**. You'll land on the integration directory, which lists all available native and third-party connections.
  </Step>
  <Step title="Find Slack in the integration directory">
    Use the search bar or scroll through the directory to locate the **Slack** card. You can also filter by category — Slack appears under **Communication**.
  </Step>
  <Step title="Click Connect and authorize via OAuth">
    Click the **Connect** button on the Slack card. Envoy redirects you to Slack's OAuth consent screen. Sign in to the Slack workspace you want to connect, review the requested permissions, and click **Allow**.
  </Step>
  <Step title="Configure notification channels">
    After authorization, Envoy returns you to the integration settings page. Select which Slack channels should receive specific event types — for example, route **Security Alerts** to `#security-ops` and **Activity Updates** to `#team-updates`. You can add multiple channels and map them to different event categories.
  </Step>
  <Step title="Test the connection">
    Click **Send Test Message** to verify that Envoy can post to your selected channels. Check Slack for the test notification. If it arrives, your integration is live. If not, review your channel permissions and try reconnecting.
  </Step>
</Steps>

<Tip>
  Once Slack is connected, consider linking **GitHub** next. The GitHub integration surfaces pull request activity and deployment events directly in your Envoy workspace, making it easy to correlate code changes with team activity.
</Tip>

## Available native integrations

Envoy ships with built-in connectors for the most common business tools. Each integration is maintained by the Envoy team and requires no custom code to set up.

| Integration | Category | What it does |
|-------------|----------|--------------|
| **Slack** | Communication | Posts real-time notifications for activity, security, and billing events to your chosen Slack channels. |
| **GitHub** | Developer Tools | Syncs repository activity, pull requests, and deployment events into Envoy's activity feed. |
| **Jira** | Project Management | Creates and updates Jira issues automatically when specific Envoy events occur, keeping your backlog in sync. |
| **Salesforce** | CRM | Links Envoy workspace members to Salesforce contacts and accounts, enabling cross-platform reporting. |
| **Zapier** | Automation | Connects Envoy to thousands of additional apps through Zapier's trigger-and-action workflow builder — no engineering required. |

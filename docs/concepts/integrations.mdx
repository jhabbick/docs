Integrations let you bring the tools your team already relies on directly into Envoy, so you can automate workflows, sync data, and receive real-time notifications without switching context. Whether you need a one-click native connection, a custom REST API integration, event-driven webhooks, or a no-code Zapier automation, Envoy provides a path that fits your technical setup. Connecting your first integration typically takes less than five minutes.

## Types of integrations

Envoy supports four categories of integrations to cover everything from quick plug-and-play connections to fully custom automations.

<Tabs>
  <Tab title="Native Integrations">
    Native integrations are first-party connections built and maintained by Envoy. They are installed in a few clicks directly from the **Integrations** page in your workspace settings, and they handle authentication automatically via OAuth. Native integrations receive ongoing updates as the connected platforms release new features.
  </Tab>
  <Tab title="API Integrations">
    If a native integration doesn't exist for your tool, you can build your own using the [Envoy REST API](/docs/api/overview). Generate an API key in **Organization Settings → API Keys**, then use standard HTTP requests to read and write data programmatically. Every resource in Envoy is available through the API.
  </Tab>
  <Tab title="Webhooks">
    Webhooks let Envoy push event data to any HTTPS endpoint you control the moment something happens — a new member joins, a workspace is created, a report is exported, and more. Configure webhooks in **Workspace Settings → Webhooks**. Each webhook delivers a signed JSON payload so you can verify its authenticity before processing.
  </Tab>
  <Tab title="Zapier">
    The Envoy Zapier app connects Envoy to thousands of additional tools without writing a single line of code. Search for "Envoy" inside Zapier to find pre-built Zap templates, or build your own triggers and actions using the available Envoy events.
  </Tab>
</Tabs>

## How integration authentication works

Envoy uses two authentication methods depending on the integration type.

**OAuth 2.0 (native integrations)**
When you install a native integration, Envoy redirects you to the third-party service's authorization page. After you grant consent, the service returns an access token that Envoy stores securely and uses for all subsequent API calls on your behalf. Tokens are encrypted at rest and refreshed automatically — you never need to manage them manually.

**API keys (custom and API integrations)**
For integrations you build yourself, generate a long-lived API key in **Organization Settings → API Keys**. Pass the key in the `Authorization` header of every request:

```http
GET /v1/workspaces HTTP/1.1
Host: api.envoy.com
Authorization: Bearer env_live_xxxxxxxxxxxxxxxxxxxx
```

Rotate API keys at any time from the same settings page. Revoked keys stop working immediately.

<Note>
  Native integrations for Slack and GitHub are available on all plans. Jira and Salesforce integrations require a **Growth** or **Enterprise** plan. Custom webhook endpoints and Zapier support are available on **Growth** and above. Check your current plan in **Organization Settings → Billing**.
</Note>

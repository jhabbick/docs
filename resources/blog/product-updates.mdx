**September 2026** — Envoy now makes it faster to start a project, keep details current, and send files with your outreach.

## Create a project in two steps

The project wizard is now **Essentials** and **Contacts**. Name the work, set a location, then pick who to reach. Add a budget or deadline later on **Overview**, or ask Envoy on **Chat**.

See [Create a project](/help-center/projects/create-a-project) and [Complete your first project](/help-center/get-started/complete-your-first-project).

## Location: ZIP or full address

On project setup, **Overview**, and **Account**, enter a ZIP code or a full address and pick a suggestion. Set a **Default project location** on **Account** so every new project starts with the right place.

See [Account settings](/help-center/account/account-settings#default-project-location).

## Update details from Chat

Ask Envoy to change your title, description, location, deadline, or budget. Overview refreshes when Envoy saves the change. You can keep chatting after outreach drafts exist, and ask Envoy to refresh drafts when the plan changes.

See [Chat planning](/help-center/projects/chat-planning).

## Attach files to outreach

Add files to drafts and replies with **Attach files**, and download files contacts send back. Follow the size hint under **Attachments** — Outlook and Microsoft inboxes may allow a smaller total than Gmail.

See [Attach files to outreach](/help-center/outreach/attach-files).
